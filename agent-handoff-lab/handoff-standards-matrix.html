the controlsWhat FIXED enforces, per exploit

Each mapping resolves to one structural control (or a small defense-in-depth stack). None of them read the wording of an attack — that is the point, and the measured reason they reach 100% where a static input filter tops out at 43% (see metrics.py) and blocks only 1 of 5 smuggling carriers (see metrics_advanced.py).

#control (FIXED build)
A1honor_untrusted_markers off (provenance) + scrub_context_on_handoff + role-gate at the tool
A2enforce_handoff_allowlist (authorize the route at the join) + ignore markers
A3enforce_tool_capabilities (per-agent least privilege) + ignore markers
A4authed_registry (operator token; no override of existing names)
A5ignore markers (provenance) + scrub retrieved external content on handoff
A6detect_handoff_loops (a directed edge can't be taken twice) + ignore markers
A7verify_agent_cards (HMAC signature vs a known federation issuer key)
A8clamp declared caps to a local per-partner grant (authN != authZ), then enforce them
A9enforce_egress_allowlist (client fetches only trusted hosts) + don't render untrusted-origin images
A10provenance_on_memory (untrusted content may not persist long-term memory) + user confirmation
A11confirm_sensitive_after_taint (taint is sticky; a trigger word doesn't launder untrusted origin)
A12provenance (encoding-independent); DETECT strip-invisibles only blocks the known carrier
how to read this as a defender

Pick your framework’s column. If you report against OWASP, the matrix tells you which of the LLM Top 10 each lab exercises and which control retires it. If you thread MITRE ATLAS, the technique IDs slot straight into a coverage map. The CWE column is for your SAST/AppSec pipeline. Every row’s control is content-independent, so it holds against paraphrase and novel encodings — the property an input filter can’t buy.

Standards are how a lab becomes a reference. Every exploit here has a catalog ID and a control that closes it.
